# 参照ファイル

実機から2026-11-11に取得したコード・設定を、元の役割ごとに配置しています。実機の配置先と取得時刻は `../evidence/source-manifest.json` を参照してください。

認証文字列、ホームWi-Fi名、カメラの識別子は例示値です。`iermu_run.sh` はセットアップ待受が通信処理を抽出する元ファイルとして収録しています。`ap/iermu_reset_capture.sh` は、その実機ファイルと実設定を使用して動作した1回限りの待受です。

このディレクトリはインストーラーではありません。特に、ネットワーク切替やファイアウォール変更を含むコードをそのまま実行しないでください。実設定済みの既存ホストを対象とする操作は `../docs/SETUP.md`、読み取り確認は `../docs/OPERATIONS.md` に記載しています。
